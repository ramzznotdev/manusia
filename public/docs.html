📖 Dokumentasi API

Base URL: https://ramzzpay.vercel.app (atau http://localhost:3000 untuk development)

🔑 Autentikasi

Semua request wajib menyertakan API Key melalui header:

x-api-key: rahasia_super_aman_123

Atau via query parameter:

?api_key=rahasia_super_aman_123

📱 OrderKouta

Request OTP

POST /api/orderkouta/get-otp

Body (JSON):

{
  "username": "0821xxxxxx",
  "password": "password_akun_orderkouta"
}

Response Sukses:

{
  "status": true,
  "message": "OTP dikirim ke 0821xxxxxx",
  "otp_method": "WhatsApp"
}

Verifikasi OTP

POST /api/orderkouta/verify-otp

Body (JSON):

{
  "otp": "123456"
}

Response Sukses:

{
  "status": true,
  "message": "Login berhasil",
  "data": {
    "name": "Nama Reseller",
    "saldo": 500000,
    "token": "abc123..."
  }
}

Mutasi QRIS

GET /api/orderkouta/mutasi?page=1

Response Sukses:

{
  "status": true,
  "data": {
    "account": { "saldo": 500000, "nama": "..." },
    "mutasi": [
      {
        "tanggal": "2024-12-20",
        "jumlah": 10000,
        "keterangan": "Pembayaran QRIS"
      }
    ]
  }
}

Profile

GET /api/orderkouta/profile

Logout

POST /api/orderkouta/logout

💳 Pakasir

Buat Transaksi

POST /api/pakasir/create

Body (JSON):

{
  "project": "slug_proyek_anda",
  "order_id": "INV-001",
  "amount": 10000,
  "pakasir_api_key": "api_key_pakasir_anda"
}

Cek Status

GET /api/pakasir/check?project=xxx&order_id=INV-001&amount=10000&pakasir_api_key=xxx

Batalkan Transaksi

POST /api/pakasir/cancel

Body (JSON):

{
  "project": "slug_proyek_anda",
  "order_id": "INV-001",
  "amount": 10000,
  "pakasir_api_key": "api_key_pakasir_anda"
}
